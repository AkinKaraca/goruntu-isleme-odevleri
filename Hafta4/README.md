# Görev 01 – Prewitt Kenar Filtresi

Bu çalışma, `duvar.jpeg` görüntüsünü gri tonlamaya çevirir, Gauss filtresiyle hafifçe yumuşatır ve 3×3 Prewitt maskesini uygular.

Kullanılan Prewitt maskesi:

```text
[-1  0  1]
[-1  0  1]
[-1  0  1]
```

## Çalıştırma

Python 3 kurulu olmalıdır. Gerekli paketleri kurun:

```bash
pip install -r requirements.txt
```

Ardından bu klasörde çalıştırın:

```bash
python "görev 01.py"
```

Betik `gri_ton.png`, `gauss_yumusatma.png` ve `prewitt_sonuc.png` dosyalarını oluşturur.
